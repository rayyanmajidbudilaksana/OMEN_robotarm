# OMEN_robotarm
A 3D printed 4-DOF robotic arm I made during Mar 2025-Jan 2026. The robot is ESP32 based, featuring wireless real-time control over WiFi. 

# Features
- 4 Degrees of Freedom with 4 MG996R servos
- ESP32-based system
- Real Time WiFi Control
- Fully 3D printed with PLA
